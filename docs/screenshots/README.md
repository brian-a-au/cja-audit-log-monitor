# TUI Screenshots

This directory contains screenshots of the CJA Audit Log Monitor TUI application.

## Capturing Screenshots

To capture screenshots of each screen:

1. Launch the TUI: `cja-audit`
2. Navigate to each screen using keyboard shortcuts
3. Capture screenshots using your system's screenshot tool

### Required Screenshots

| File | Screen | Shortcut |
|------|--------|----------|
| `dashboard.png` | Dashboard | `d` |
| `log-browser.png` | Log Browser | `l` |
| `monitor.png` | Real-Time Monitor | `m` |
| `statistics.png` | Statistics | `s` |
| `alerts.png` | Alert Rules | `a` |
| `settings.png` | Settings | `c` |

### Recommended Terminal Size

For consistent screenshots, use a terminal window of approximately:
- Width: 120 columns
- Height: 40 rows

### macOS Screenshot Tips

- `Cmd + Shift + 4` then `Space` to capture a window
- Save directly to this directory
