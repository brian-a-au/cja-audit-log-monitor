# Security policy

## Report a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub instead. Go to the **Security** tab of this repository and choose **Report a vulnerability**. I will reply as soon as I can and keep you updated while I work on a fix.

## Scope

This tool handles Adobe OAuth credentials and reads audit log data. Reports about these topics are especially welcome:

- Credentials or tokens that appear in logs, output, exports, or screenshots.
- Unsafe handling of the `.env` file or the config file.
- Webhook or Slack delivery that sends more data than it should.

## Supported versions

Only the latest release receives security fixes.
